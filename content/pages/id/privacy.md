**Singkatnya:** aplikasi Patchland tidak mengumpulkan informasi pribadi dan tidak berisi analitik maupun iklan. Situs web ini adalah situs statis tanpa analitik dan tanpa cookie, serta tidak meminta nama, email, atau akun.

Tanggal berlaku: {{EFFECTIVE}} · Operator: {{OPERATOR}}

## 1. Informasi yang kami kumpulkan

Patchland: Claim It All ("Aplikasi") adalah game seluler yang dioperasikan oleh pengembang perorangan, {{OPERATOR}}. Aplikasi tidak memiliki akun atau proses masuk, dan tidak mengumpulkan maupun mengirim ke server mana pun informasi pribadi seperti nama, email, detail kontak, lokasi, atau pengenal perangkat.

Kemajuan permainan (peta, bintang, kartu Album Penguasa, catatan harian) dan pengaturan (suara, getar, pola buta warna) disimpan hanya di perangkatmu dan dihapus darinya saat kamu menghapus Aplikasi. Game ini berjalan tanpa koneksi internet.

Aplikasi tidak berisi iklan, analitik, maupun SDK pelacakan.

## 2. Situs web

Situs web ini (patchland.ipe.rest) adalah situs statis. Situs ini tidak memakai alat analitik dan tidak menyetel cookie. Jika kamu memilih bahasa, browsermu mungkin menyimpan pilihan itu hanya di perangkatmu sendiri; pilihan itu tidak pernah dikirim kepada kami. Halaman memakai font bawaan perangkatmu. Situs ini di-host di GitHub Pages, yang dapat memproses informasi permintaan web biasa (seperti alamat IP-mu) sesuai kebijakan GitHub sendiri.

## 3. Pihak ketiga

Kami tidak menjual informasimu dan tidak membagikannya kepada siapa pun. Saat Aplikasi dirilis, pengunduhan akan ditangani oleh toko aplikasi sesuai kebijakan privasi mereka masing-masing.

## 4. Pertanyaan dan hakmu

Untuk meminta akses, koreksi, penghapusan, atau penghentian pemrosesan informasi pribadimu, atau untuk mengajukan pertanyaan apa pun, tulislah ke [{{EMAIL}}](mailto:{{EMAIL}}). Karena Aplikasi dan situs web tidak mengumpulkan informasi pribadi, biasanya kami tidak menyimpan apa pun untuk dicari; korespondensi email dapat kami cari dan hapus.

## 5. Anak-anak

Aplikasi tidak ditujukan untuk anak di bawah 14 tahun (atau usia minimum di wilayahmu), dan Aplikasi tidak mengumpulkan informasi pribadi dari pengguna mana pun.
