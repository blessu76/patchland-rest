## 1. Welche Daten wir erheben

Patchland: Claim It All („die App“) ist ein Mobilspiel, das von einem einzelnen Entwickler, {{OPERATOR}}, betrieben wird. Die App hat weder Konten noch Anmeldung und erhebt oder sendet keine personenbezogenen Daten wie Name, E-Mail, Kontaktdaten, Standort oder Gerätekennungen an einen Server.

Dein Spielfortschritt (Karte, Sterne, Karten des Lord-Albums, Tagesergebnisse) und deine Einstellungen (Ton, Vibration, Muster für Farbenblindheit) werden ausschließlich auf deinem Gerät gespeichert und beim Löschen der App von diesem entfernt. Das Spiel funktioniert ohne Internetverbindung.

Die App enthält keine SDKs für Werbung, Analyse oder Tracking.

## 2. Die Website

Diese Website (patchland.ipe.rest) ist eine statische Seite. Sie verwendet keine Analysewerkzeuge und setzt keine Cookies. Wenn du eine Sprache wählst, speichert dein Browser diese Auswahl möglicherweise nur auf deinem eigenen Gerät; sie wird nie an uns gesendet. Die Seiten verwenden die Schriftarten deines Geräts. Die Website wird auf GitHub Pages gehostet, das übliche Informationen zu Webanfragen (z. B. deine IP-Adresse) nach den eigenen Richtlinien von GitHub verarbeiten kann.

## 3. Dritte

Wir verkaufen deine Daten nicht und geben sie an niemanden weiter. Nach der Veröffentlichung der App werden Downloads von den App-Stores nach deren eigenen Datenschutzrichtlinien abgewickelt.

Die App richtet sich nicht an Kinder unter 14 Jahren (oder das Mindestalter in deiner Region), und sie erhebt von keinem Nutzer personenbezogene Daten.
